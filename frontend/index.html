Documentación Técnica de Endpoints

La API gestiona la información mediante los siguientes métodos y estructuras:

GET /pets

Salida: Devuelve la lista completa de todas las mascotas en formato JSON.

[{"id": 1, "name": "Toby", "species": "Perro", "age": 3}]
POST /pets

Entrada: Requiere un objeto JSON con las propiedades de la mascota.

{"name": "string", "species": "string", "age": "number"}
DELETE /pets/{id}

Parámetro: Recibe el identificador numérico único (ID) en la URL para eliminar el registro.

{"message": "Pet deleted successfully"}
